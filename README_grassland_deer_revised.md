# 🌱 我們想解開一個生活中的謎題

清明祭祖、節慶與日常祭祀中，

焚燒金紙是許多人熟悉的生活文化。

但當火焰熄滅之後，

故事真的結束了嗎？

如果一粒灰燼離開金爐，

它會去哪裡？

會留在土壤？

會跟著雨水移動？

會進入植物？

甚至繼續影響我們生活的環境嗎？

**我們不知道。**

所以，

想和大家一起找答案。

# 🔥 為什麼這個問題值得被看見？

近年台灣曾出現多起公墓、墓區與周邊雜草火警。

在乾燥、強風環境下，

尚未完全熄滅的火星、紙灰或其他火源，

都有可能被風吹散，

讓原本很小的火，

延燒成更大的環境災害。

這些事件提醒我們：

> **焚燒結束，不代表影響也跟著結束。**

火焰看得見，

但火焰之後留下的灰燼，

往往更容易被忽略。

而這正是我們想追下去的問題。

---

# 🧩 我們真正想研究的，不只是火

野火是「立即看得見」的風險。

但我們更好奇的是另一段：

### **火熄滅之後，灰燼去了哪裡？**

灰燼可能：

🌬️ 被風吹走

💧 被雨水沖刷

🌱 留在土壤

🌿 接觸植物

這些看不見的移動，

會不會形成另一條環境影響鏈？

這就是我們想研究的：

## **灰燼 → 雨水 → 土壤 → 植物**

我們不先假設答案。

只讓實驗和證據告訴我們結果。

# ❓ 我們的核心問題

我們想一步一步問：

**1. 灰燼進入土壤後，土壤會發生什麼變化？**

**2. 灰燼遇到雨水後，哪些物質可能被帶走？**

**3. 這些變化會不會影響植物的生長？**

**4. 如果真的觀察到影響，它能不能被重複驗證？**

不把「可能」當成「一定」。

不把「相關」直接當成「因果」。

這也是我們學習科學最重要的一部分。

---

**不用猜，讓證據告訴我們答案。**

# 🧪 我們會怎麼比較？

研究會盡量讓條件保持一致，

只改變我們真正想觀察的因素。

例如：

🌱 沒有加入灰燼的對照組

🌱 加入不同量灰燼的實驗組

💧 模擬雨水沖刷

🌿 持續記錄植物變化

📏 比較高度、葉片、生長狀況等資料

如果結果和原本猜的不一樣，

我們就修改想法，

再做一次。

> **科學不是證明自己是對的，  
> 而是願意讓證據修正自己的想法。**

我們希望孩子最後看到的，

不只是「金紙」，

而是一個完整的環境系統：

**燃燒**

↓

**灰燼**

↓

**風與雨**

↓

**土壤與水**

↓

**我們生活的環境**

一個很小的生活行為，

有時可能連接到很長的環境故事。

# ⚠️ 我們不是要責怪誰

祭祖與祭祀，

這個研究不是要否定傳統，

也不是先替任何行為下結論。

我們想做的是：

**理解。**

理解火可能帶來的風險，

理解灰燼可能走過的路，

也一起尋找

更安全、

更友善環境、

也能尊重文化的做法。
