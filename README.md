## 🧭 一眼看懂〈追灰〉

**為什麼要做（WHY）→ 怎麼研究（HOW）→ 社區調查與訪談 → 校園教育推廣 → 進度與未來規劃**

〈追灰〉不是要證明燒金紙一定有害，也不是要求所有人停止燒金紙。這是一個由孩子出發的初步公民科學行動：從環境問題提出疑問，用小型實驗取得初步線索，再理解社區的不同選擇，最後嘗試把觀察與討論帶進校園。

## 01｜WHY：為什麼要關注容易被忽略的二次污染？

燒金紙時，我們容易注意煙霧、氣味與火災風險；但是火熄滅後，灰燼去哪裡了？它可能隨風散落，也可能接觸雨水與土壤。**燃燒當下的煙霧容易引起注意，但看不見的灰燼去向容易被忽略。** 灰燼若透過風、雨進入土壤或水體，部分物質可能留在環境中並造成後續影響；影響是否發生、持續多久及程度如何，仍取決於灰燼成分、暴露條件與環境特性，不能預先下結論。

因此，我們首先問：「金紙灰燼接觸水後，是否可能影響植物生長？」完整環境問題非常複雜，先縮小研究範圍，才有可能做出清楚、可比較的觀察。

## 02｜怎麼做？HOW：綠豆實驗（進行中）

**研究目的**：初步比較清水與金紙灰水處理下，綠豆的發芽及生長情況，尋找是否有值得後續研究的差異。

**目前設計**：使用玉皇宮採集的灰燼樣本，製備 **10 g/L** 灰水；以清水作為對照。盡量讓兩組的種子、盆器、土量、光照、澆水體積和觀察時間一致；目前規劃每組約 **3–5 盆**、每盆 **3 顆綠豆**，實際執行以當次紀錄為準。

**觀察項目**：發芽情況、株高、葉片顏色與外觀；同時視設備與操作條件記錄 pH、EC、鹽度等輔助資訊。**pH** 反映酸鹼環境，可能影響養分有效性；**EC** 反映水中導電離子的整體程度，但不能辨認具體物質；**鹽度** 反映儀器估算的鹽分指標，鹽分過高可能妨礙植物吸水。這三項都**不能單獨證明污染或重金屬含量**，且多功能筆的鹽度、TDS 往往由 EC 換算，不是獨立化學分析。以照片及日期記錄變化，並保留異常、誤差和操作調整。

**科學界線**：即使觀察到差異，也不能直接推定真實環境已受污染，更不能推論人類健康風險或所有金紙灰燼的影響；若沒有差異，也不代表灰燼完全無影響。

## 03｜走進社區：理解、深度訪談與推廣（規劃中）

**為什麼接著做社區調查？** 植物實驗只能探索部分自然現象，無法解釋人們為什麼燒或不燒金紙。傳統、信仰、家庭習慣與環境觀點，都值得先理解、再討論。

- **問卷調查**：詢問民眾是否燒金紙、主要原因、對灰燼後續影響的認識及想法，讓燒與不燒者都能表達立場。
- **深度訪談選擇不燒金紙的信眾**：先理解其信仰如何實踐、選擇不燒的原因與歷程，以及社區的看法；在分享〈追灰〉實驗的**實際初步結果**後，再詢問心得、疑問與建議。

**調查原則**：不預設「正確答案」，避免誘導式提問，尊重不同信仰與個人選擇；研究結果仍需如實呈現，即使與最初假說不同。

## 04｜從理解走向行動：校園公民教育（暫定）

**為什麼要進校園？** 將科學觀察與社區觀點帶回同學身邊，讓更多人練習以證據提問、以尊重進行討論，而非只接受單一結論。

**推廣對象（待確認）**：國小與幼兒園分齡設計。面向**國小生**，以科學圖片、簡易觀察展示、互動討論與海報介紹灰燼後續去向及證據的限制；面向**幼兒園**，以繪本故事、角色扮演、配對遊戲和手作活動認識愛護環境的行動。內容尊重不同家庭信仰，不要求孩子做特定宗教選擇。**預計 2027 年 5–6 月（暫定）**，依學校與小隊安排再確認。
